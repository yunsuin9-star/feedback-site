# 04. 서답형 피드백

Status: open

## 핵심 장면

선생님이 서답형 답변을 읽고 점수와 피드백을 남기면 학생에게 자기 피드백이 보인다.

## 범위

- 선생님이 제출된 학생별 서답형 답변을 확인하는 화면
- 선생님이 서답형 점수와 피드백을 입력하고 저장하는 흐름
- 학생이 저장된 자신의 서답형 답변, 점수, 피드백을 확인하는 화면

## 완료 기준

- 브라우저에서 선생님이 학생의 서답형 답변을 볼 수 있다.
- 선생님이 점수와 피드백을 입력하고 저장할 수 있다.
- 저장 전에는 학생 화면에 점수와 피드백이 보이지 않는다.
- 저장 후에는 해당 학생 화면에 자신의 서답형 답변, 점수, 피드백이 보인다.
- 학생 화면에서 다른 학생의 답변이나 피드백은 보이지 않는다.
