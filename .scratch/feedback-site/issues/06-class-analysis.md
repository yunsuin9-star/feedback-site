# 06. 학급 전체 오개념 분석

Status: open

## 핵심 장면

선생님이 6주 동안의 결과를 확인하면 학생 이름 없는 학급 전체 오개념 위계와 누적 변화가 보인다.

## 범위

- 최근 6주의 결과를 주 단위로 집계
- 핵심 개념과 오개념의 2단계 위계 표시
- 주별 오개념 수와 6주 누적 변화 표시
- 학생 이름이나 개인 식별 정보 없이 학급 전체 결과 표시

## 완료 기준

- 브라우저에서 선생님이 최근 6주의 결과를 주별로 볼 수 있다.
- 학생 이름 없이 핵심 개념과 오개념의 위계가 보인다.
- 주별 오개념 수가 보인다.
- 6주 동안의 오개념 누적 변화가 보인다.
- 개인별 답변, 점수, 피드백, 이름은 분석 화면에 보이지 않는다.
