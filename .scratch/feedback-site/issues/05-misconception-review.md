# 05. 오개념 확인과 학생별 결과

Status: open

## 핵심 장면

사이트가 객관식 오답과 서답형 답변을 바탕으로 오개념 후보를 제안하고, 선생님이 확인·수정하면 학생별 오개념 결과가 보인다.

## 범위

- 학생별 객관식 오답과 서답형 답변 확인
- 02번 티켓에서 GPT가 추천하고 선생님이 저장한 예상 오개념을 후보로 활용
- 학생의 답변을 근거로 오개념 후보를 학생별로 표시
- 선생님이 후보를 확인·수정·삭제·추가하고 저장하는 흐름
- 선생님이 확정한 학생별 오개념 결과를 학생에게 표시

## 완료 기준

- 브라우저에서 선생님이 학생별 객관식 오답과 서답형 답변을 볼 수 있다.
- 학생별 오개념 후보가 보인다.
- 선생님이 오개념 후보를 확인하거나 수정할 수 있다.
- 선생님이 확정한 오개념을 저장할 수 있다.
- 학생 화면에는 선생님이 확정한 자신의 오개념만 보인다.
- 선생님이 확정하지 않은 오개념 후보는 학생에게 보이지 않는다.
