# 02. 과제 생성과 공개

Status: open

## 핵심 장면

선생님이 객관식 2개, 서답형 1개, 공개일·마감일을 입력한다. 문제 내용을 바탕으로 GPT가 핵심 개념과 예상 오개념을 추천하고, 선생님이 확인·수정한 뒤 과제를 공개한다.

## 범위

- 객관식 문제 2개의 문제 내용, 선택지, 정답 입력
- 서답형 문제 1개의 문제 내용 입력
- 공개일과 마감일 입력
- 문제 내용을 GPT에 전달해 핵심 개념과 예상 오개념을 추천받는 흐름
- 선생님이 GPT 추천 결과를 수정·삭제·추가하는 흐름
- 선생님이 저장한 최종 핵심 개념과 예상 오개념으로 과제를 공개하는 흐름
- 화면은 `index.html` 하나에 담고, 과제와 최종 입력 결과는 브라우저 `localStorage`에 저장
- GPT 호출은 API 키를 `index.html`에 노출하지 않는 최소 API 프록시를 사용하며, 별도 데이터베이스는 사용하지 않음

## 완료 기준

- 브라우저에서 선생님이 객관식 2개와 서답형 1개의 문제를 입력할 수 있다.
- 선생님이 공개일과 마감일을 입력할 수 있다.
- 선생님이 `AI 추천`을 실행하면 입력한 문제에 대한 핵심 개념과 예상 오개념이 입력란에 표시된다.
- 선생님이 GPT 추천 결과를 수정·삭제·추가할 수 있다.
- 선생님이 수정한 최종 핵심 개념과 예상 오개념을 저장할 수 있다.
- 공개일 전에는 학생에게 과제 내용이 보이지 않는다.
- 공개일 이후에는 학생에게 선생님이 저장한 최종 과제가 보인다.
- 마감일이 공개일보다 빠르거나 같으면 저장되지 않고 오류가 보인다.
