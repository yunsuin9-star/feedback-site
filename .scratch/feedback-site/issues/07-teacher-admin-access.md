# 07. 선생님 관리자 화면 접근 제어

Status: open

## 핵심 장면

선생님 역할을 선택한 사람이 관리자 비밀번호를 입력해야 선생님 화면을 열 수 있고, 인증 전에는 학생 글과 선생님만 보는 내용이 보이지 않는다.

## 범위

- 선생님 역할 선택 후 관리자 비밀번호 입력 화면 표시
- 실습용 관리자 비밀번호 `teacher-demo` 검증
- 올바른 비밀번호 입력 후 선생님 관리자 화면 열기
- 잘못된 비밀번호 입력 시 관리자 화면 접근 차단 및 오류 표시
- 관리자 인증 전 학생 제출 답변, 점수, 피드백, 오개념, 학급 분석 등 선생님 전용 내용 비노출
- 학생 수업 참여 흐름은 관리자 비밀번호 없이 이용 가능

## 완료 기준

- 브라우저에서 `선생님`을 선택하면 관리자 비밀번호 입력 화면이 보인다.
- `teacher-demo`를 입력하면 선생님 관리자 화면이 보인다.
- 다른 비밀번호나 빈 비밀번호를 입력하면 관리자 화면으로 이동하지 않고 인증 실패 안내가 보인다.
- 관리자 비밀번호를 입력하기 전에는 학생 제출 글, 점수, 피드백, 오개념, 학급 분석 내용이 화면에 보이지 않는다.
- 관리자 비밀번호를 입력하기 전에는 수업 생성·과제 관리 등 선생님 전용 화면이 보이지 않는다.
- 브라우저에서 `학생`을 선택하면 관리자 비밀번호 없이 학생 인증과 수업 참여 화면을 이용할 수 있다.
