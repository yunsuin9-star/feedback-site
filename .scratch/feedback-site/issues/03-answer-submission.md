# 03. 답변 제출과 수정

Status: open

## 핵심 장면

학생이 문제를 풀어 제출하면 객관식 정답 여부를 확인할 수 있고, 마감 전 최대 2회 수정할 수 있다.

## 범위

- 객관식 2개와 서답형 1개의 답변 입력
- 답변 제출 및 제출 상태 표시
- 객관식 답변과 정답 비교 결과 표시
- 마감 전 답변 수정 제출
- 수정 횟수 제한과 마감 시 제출·수정 제한

## 완료 기준

- 브라우저에서 학생이 객관식 2개와 서답형 1개에 답변할 수 있다.
- 학생이 답변을 제출하면 제출한 답변과 제출 상태가 보인다.
- 객관식 답변마다 정답 또는 오답이 보인다.
- 마감 전에는 답변을 최대 2회 수정 제출할 수 있다.
- 현재 수정 횟수와 남은 수정 횟수가 보인다.
- 2회 수정한 뒤에는 수정할 수 없다.
- 마감 후에는 제출과 수정 버튼을 사용할 수 없다.
