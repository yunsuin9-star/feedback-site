# 01. 수업 참여

Status: open

## 핵심 장면

선생님이 수업 코드를 발급하고, 학생이 테스트용 전화번호 인증 후 수업 코드를 입력하면 해당 수업에 참여한다.

## 범위

- 선생님이 수업 코드를 발급하는 화면
- 학생이 전화번호와 테스트용 인증번호를 입력하는 화면
- 학생이 수업 코드를 입력해 수업에 참여하는 흐름
- 실제 문자 발송 없이 테스트용 인증번호로 인증하는 흐름

## 완료 기준

- 브라우저에서 선생님이 수업 코드를 발급할 수 있다.
- 브라우저에서 학생이 전화번호와 테스트 인증번호를 입력할 수 있다.
- 학생이 수업 코드를 입력하면 해당 수업 화면으로 이동한다.
- 존재하지 않는 수업 코드를 입력하면 참여 실패 안내가 보인다.
